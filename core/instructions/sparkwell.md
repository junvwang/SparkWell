# Sparkwell Project Instructions

## Activation

SparkWell is opt-in through `/spark-design`, `/spark-config`, `/spark-impl`, and `/spark-test`. Each command runs only its named Agent Skill.

## Pending Proposals

After `/spark-design` or `/spark-config` produces a proposal, use a host-provided decision UI when available. Otherwise, continue the latest unambiguous proposal only from a direct `Revise: <comments>`, `Finalize`, or `Cancel` reply.

UI dismissal, silence, and other feedback do not finalize a proposal. Keep proposal and approval state in chat only.
