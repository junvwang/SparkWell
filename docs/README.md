# SparkWell Documentation

## Start Here

- New to SparkWell: read the [project overview](../README.md), then the [usage guide](usage.md).
- Configuring or implementing a project: use the [usage guide](usage.md) and the relevant Agent Skill under [`skills/`](../skills/).
- Using OpenAPI or building another technology extension: read [Optional Implementation Packs](implementation-packs.md).

| Document | Role |
